# 使用说明

[返回首页](../README.md)

第一次使用，可以先完成一段简单行程：**选一条轨道 → 确定方向 → 向前推进 → 调整起终点 → 导出 KML**。熟悉后，再使用跨线连接和沿关系继续。

> **当前不支持自动折返处理，只能手动处理。** 此限制适用于自动推进、跨线连接和沿关系继续。

## 1. 选一条轨道作为起点

1. 搜索城市、车站或地址，将地图移到出发位置。
2. 在附近右键，选择查询半径：100、250 或 500 米。
3. 点击列表中的轨道，查看名称和“直接所属关系”，确认需要的线路。点击关系名称可以在地图上预览。
4. 点击轨道右侧的双右箭头，开始探索。知道轨道 ID（`way_id`）时，也可以直接在上方输入。

刚开始只加入这一条轨道，不会立即自动推进，方便检查位置。这里的一条轨道是 OSM 中的一条 way，可能跨过多个车站，并不等于一站路。

地图放大到 16 级后会显示车站图标，鼠标悬浮可查看站名及线路。地点搜索可以找到全球地点，但轨道和车站只覆盖已加载的数据地区。

## 2. 选一个方向，向前推进

### 用下一条轨道确定方向

选好首条轨道后，查看“可选相连轨道”。根据地图，选择想去的方向上的下一条轨道；程序会根据前后轨道的连接位置推断行进方向。

不确定候选在哪时，可以用旁边的定位图标查看范围。选错了，用当前轨道旁的双左箭头退回一条，再重新选择。

### 自动推进

点击候选轨道的**名称**，会先加入这条轨道，再沿前进方向自动推进：

- 只有唯一明确的连接时，继续加入后面的轨道。
- 遇到分支、闭环、折返、无候选或方向不明确时，停下来让你选择。
- 只想前进一条、逐步检查时，点击候选旁的**双右箭头**。

### ⭐ 推荐

候选旁的 **⭐ 表示推荐走这条**。确定行进方向后，程序先筛出连接位置明确、连接处转向小于 90° 的候选，再按下面的优先级依次比较：

1. **优先从当前轨道末端接出**，其次才考虑从中途岔出去。
2. **当前不在辅助轨道上时，优先继续走非辅助轨道**，降低站场线、侧线、支线和渡线的优先级（OSM 的 `service=yard/siding/spur/crossover`）。当前已经在这些辅助轨道上时，这一项不作区分。
3. **优先名称相同的轨道**，按当前轨道和候选轨道的 OSM `name` 完全一致判断；没有名称不算同名。
4. **最后比较转向角度，优先更顺直的方向**。使用连接点两侧各约 30 米的轨迹判断走向，轨迹不足 30 米时使用已有部分。

这是逐项排序：前一项相同时，才比较后一项。例如同样从末端接出、用途也相同的两个候选，同名轨道会排在更直但不同名的轨道前面。

方向尚未确定、没有符合条件的候选，或最优两个候选无法区分时，不显示星标。与当前轨道有多个共用节点、连接位置存在歧义的候选也不参与推荐；未获推荐不代表不能手动选择。

星标只是帮助判断，**有星标的分支仍由你点击确认**，也可以选择其他候选。

### 一直推进到需要的位置

重复“选择候选 → 自动推进 → 分支处确认”，直到到达目的地，或本段没有更多相连轨道。

没有候选表示当前数据和行进方向下没有可继续的轨道，不一定是现实中的线路终点。到达下车站也不必继续走到轨道末尾：如果已经推进过站，下一节可以直接截掉多余部分。

## 3. 轨道跨过车站时，截取起终点

一条 way 不一定以车站为端点。例如它依次经过 A、B、C 站，而你只从 B 站出发，或只坐到 B 站，保留整条轨道就会多出一截。这时使用下面两个操作。

### “从此开始本段”：去掉上车之前的部分

**场景：首条轨道穿过上车站，你想从轨道中间开始。**

1. 加入首条轨道后，在地图上靠近上车位置的轨道处右键。
2. 选择“从此开始本段”。
3. 从列表中的 `way-A` / `way-B` 选择出发方向，再继续推进。

这个操作要在**本段只有首条轨道时**完成；如果已经推进多条，需先退回首条。没有指定起点时，按整条轨道开始，不显示 A/B 方向选项。

### “在此结束本段”：去掉下车之后的部分

**场景：自动推进越过了下车站，或者下车站位于末条轨道中间。**

1. 在地图上靠近下车位置的已选轨道处右键。
2. 选择“在此结束本段”。
3. 程序将位置贴合到轨迹上，保留到这里为止的行程，去掉之后的部分，包括后续整条轨道。

不需要一条条退回，也不要求下车位置就在当前末条轨道上。点击位置需在轨迹 150 米以内；尚未确定方向时，该操作不可用。

截取后，地图、距离和导出的 KML 会一起更新。**“退回一条轨道”不是撤销截取**：它仍会移除末尾一条轨道的剩余部分。

## 4. 换乘、导出与保存

### 换乘后开始下一段

需要从另一条不相连的轨道继续时，重新搜索或在地图上右键选择轨道，使用“作为下一段继续”。已有行程会保留，新轨道成为下一段的起点。

“第 1 段、第 2 段”表示换乘前后的独立行程，每段可以包含多条 way。导出时放在同一个文件中，换乘处不强行连线。

### 下载 KML

1. 选择导出全部行程或某一段。
2. 点击“下载 KML”。
3. 检查建议的起点、换乘站和终点名称，需要时手动修改，再下载。

文件名形如 `A → B → C.kml`；换乘站名称不同时，形如 `A → B1（B2） → C.kml`。名称根据本地车站数据建议，仅按距离找到的候选会标明“附近车站”。

KML 保留截取后的准确起终点和轨道颜色。颜色优先取轨道自身或可确定的所属线路色，无法确定时使用本段备用色，与地图一致。

**行程只保存在当前页面内存中，刷新或关闭页面前请先导出。** 不同标签页的行程互不影响；“清空”会清除当前页面的全部行程。

地点搜索历史单独保存在浏览器本地，最多 10 条，可在搜索下拉列表中清空。

如需 Overpass 查询，可在“更多”中复制，再到 [Overpass Turbo](https://overpass-turbo.eu/) 使用。Overpass 返回完整 way，无法表达截取后的部分轨道；需要准确起终点时使用 KML。

## 5. 进阶：跨线连接到目标轨道

当行程需要从当前线路转入另一条线路，但尚不明确连接位置及途经轨道时，可使用此功能查找连接路径。

### 怎么操作

1. **在连接区域之前停下。** 如果已经推进过头，在已选轨迹上右键，用“在此结束本段”截到进入站场或分岔区域之前。
2. **在连接区域之后找目标轨道。** 在想继续前往的线路上右键查询，选中出站后或分岔后的轨道，查看名称和所属关系。这里只选中目标，不必先添加到行程或开始新段。
3. **点击目标轨道旁的链条图标“连接到此轨道”。** 程序从当前行程末端查找通往目标的路径。
4. **预览后确认。** 橙色表示将加入的轨迹，红色表示将移除的轨迹。点击“确认连接”后接入当前段，再继续推进；取消或查找失败不会修改行程。

查到的是 OSM 数据中的可能路径，不保证是列车实际使用的进路。

### 场景一：京广高铁 → 徐兰高铁

想经郑州东从京广高铁转到徐兰高铁，但不知道站内经过哪些渡线。可以把当前行程停在京广高铁进站前，以徐兰高铁出站方向的轨道为目标，让程序尝试补齐中间连接。

### 场景二：京急本线 → 京急空港线

从品川方向前往羽田机场，想知道本线如何在京急蒲田转入空港线。可以把当前行程停在蒲田进站前，以空港线朝糀谷方向的轨道为目标，尝试查找分岔路径。

### 找不到直接连接时

程序会尝试回退最多 10 条已选轨道寻找连接，优先少回退，再按距离选择路径。

如果仍无法直接接到目标，还会尝试同线的可达汇入点，并标出位置和偏移距离；需点击“改接推荐位置”才会采用。每次尝试最多查找 50 公里，复杂网络还有搜索量限制，超限时可选择更近的目标再试。

如果是下车换乘、两段之间无需连线，使用“作为下一段继续”。

## 6. 进阶：沿关系继续

**场景：已经确认某条线路，想沿它连续前进，减少沿途逐条选择。**

这里的“关系”是 OSM 将一组轨道组织在一起的记录，可能代表一条线路。可以先预览，确认它是不是你要走的路线。

1. 点击“当前轨道”的名称或 ID，展开详情和“直接所属关系”。
2. 点击关系名称，预览其中与当前轨道相连的部分。
3. 将鼠标放在关系右侧的双右箭头上，预览本次将加入的前方轨迹。
4. 点击双右箭头“沿此关系继续”，加入前方没有歧义的连续轨道。

如果首条完整轨道位于这条连续链的端头，可以自动确定向链内前进的方向；在链中间时，需先选择下一条轨道，或通过“从此开始本段”指定方向。

沿关系继续会在缺口、分支或即将接回已选轨迹前停下。关系外的岔道不会阻止已确定的连续部分；但如果下一条 way 中途存在共点分支，会停在它之前，交给候选列表手动选择。

双箭头不可用时会置灰，悬浮可查看原因。关系预览只显示相连部分，隐藏的轨道数量会在页面提示；相连并不代表运行方向一定相同。

如果一次加过了下车站，用“在此结束本段”截取即可。“退回一条轨道”仍然每次只退一条，不会一次撤销整组加入。
