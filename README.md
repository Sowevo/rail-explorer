# Rail Explorer

基于本地 OpenStreetMap（OSM）数据，在地图上选择铁路轨道、规划多段行程，并导出 KML。支持铁路、地铁、轻轨和单轨铁路（`rail`、`subway`、`light_rail`、`monorail`）。

- 右键查询附近轨道，选中后查看直接所属关系和线路信息。
- 手动选择分支，在连接关系明确时自动推进；支持单条前进、退回和起终点截取。
- 换乘后开启独立行程段，导出到同一个 KML 文件，换乘处不连线。
- 使用本地车站数据建议导出名称，也可手动修改。

## 1. 安装

需要 Python 3.9+。以下命令适用于 macOS/Linux；前端样式、地图底图和在线地名搜索需要网络。

```bash
git clone https://github.com/Sowevo/rail-explorer.git
cd "rail-explorer"
python3 -m venv ".venv"
source ".venv/bin/activate"
python -m pip install -r "requirements.txt"
```

下文命令均在项目根目录、已激活的虚拟环境中执行。

## 2. 准备地图数据

### 2.1 获取 PBF 下载地址

打开 [Geofabrik 下载站](https://download.geofabrik.de/)，按洲、国家或地区找到需要的数据，复制 `.osm.pbf` 文件链接，而不是 `.html` 详情页地址。

常用地址：

| 区域 | 下载链接 |
| --- | --- |
| 中国 | [china-latest.osm.pbf](https://download.geofabrik.de/asia/china-latest.osm.pbf) |
| 日本 | [japan-latest.osm.pbf](https://download.geofabrik.de/asia/japan-latest.osm.pbf) |
| 其他地区 | 在 [Geofabrik](https://download.geofabrik.de/) 中选择区域，部分国家还提供更小范围的数据 |

### 2.2 生成索引：两种方式任选其一

**方式一：传入链接，自动下载并生成索引。**

```bash
python "app/parse_osm.py" "https://download.geofabrik.de/asia/japan-latest.osm.pbf"
```

无需 aria2，支持多连接下载、断点续传和重定向。下载中断后重新执行同一命令即可。

**方式二：自己下载，再传入本地文件路径。**

```bash
python "app/parse_osm.py" "/实际路径/地图.osm.pbf"
```

本地文件直接读取，不复制或删除原文件。两种方式都必须传入参数，没有默认数据源。

每次解析一个 PBF，覆盖现有索引，不合并多个文件。更新数据前先停止服务，生成完成后再启动。**已有索引且数据无需更新时，直接跳到第 3 节。**

### 2.3 保存位置

| 内容 | 位置 |
| --- | --- |
| 自动下载的 PBF | 系统 Downloads 目录下的 `rail/<链接哈希>/source.osm.pbf` |
| 手动下载的 PBF | 传入的文件路径，位置不变 |
| 生成的索引 | 项目中的 `app/data/` |
| 服务日志 | `app/data/logs/rail.log` |

索引包括 `node_to_ways.pkl`、`way_to_nodes.pkl`、`node_coords.pkl`、`way_to_meta.pkl`、`relations.pkl`、`stations.pkl` 六个文件，分别保存轨道连接、节点、坐标、属性、关系和车站数据。

**生成索引后可以删除原始 PBF。** 保留六份索引即可运行和重启服务；只有更新或重建索引时才需要 PBF。索引、日志和虚拟环境均已由 `.gitignore` 忽略，不上传 Git。

## 3. 启动与停止

在项目目录、已激活的虚拟环境中启动：

```bash
python "app/app.py"
```

浏览器访问 [http://127.0.0.1:5050/](http://127.0.0.1:5050/)。服务自动加载 `app/data/` 中的索引，无需再次导入 PBF。

以后打开新终端时，先进入你保存项目的位置并激活环境，再启动：

```bash
cd "/你的项目路径/rail-explorer"
source ".venv/bin/activate"
python "app/app.py"
```

在服务终端按 `Ctrl+C` 停止；执行 `deactivate` 退出虚拟环境。

## 4. 地图操作

### 找到轨道

1. 使用地图上的地点搜索定位城市、车站、机场或地址，也可以直接移动地图。
2. 在目标附近右键，选择查询半径：100、250 或 500 米。
3. 点击附近轨道，查看名称、直接所属关系和原始标签，确认需要的线路。
4. 点击“从此轨道开始探索”。也可以直接输入轨道 `way_id` 开始。

点击轨道的“直接所属关系”时，只更新地图预览并标记选中的关系，左侧保留当前轨道详情。预览仅高亮该关系内与所选轨道相连的部分；有不相连的轨道时显示“仅显示相连轨道 · 已隐藏 N 条”。筛选不修改原始关系数据，相连不代表运行方向相同。

地点搜索使用在线 Nominatim 服务，可搜索全球地点；轨道、关系和车站使用本地 PBF 索引，只覆盖已导入区域。搜索结果和本地搜索历史均支持方向键选择、回车确认。

地图放大到 16 级后，按可视范围显示车站图标；悬浮查看站名及线路。车站不绘制建筑或站台轮廓。

### 前进、退回与换乘

| 操作 | 行为 |
| --- | --- |
| 添加每段首条轨道 | 只加入这一条，留出确认位置和起点的机会 |
| 点击候选轨道名称 | 加入轨道，并在前进方向只有唯一明确连接时自动推进 |
| 候选旁的双右箭头 | 只前进一条，不连续推进 |
| 当前轨道旁的双左箭头 | 移除末尾一条轨道，不移动地图 |
| 轨道旁的定位按钮 | 查看对应轨道范围 |
| 作为下一段继续 | 从另一条不相连的轨道开启新段，保留已有行程 |

自动推进遇到分支、闭环、折返、无候选或方向不明确时停止，由你继续选择。⭐ 表示推荐候选，不限制手动选择其他轨道。

“第 1 段行程、第 2 段行程”表示换乘前后的独立行程段；每段可包含多条 OSM 轨道（way）。

### 跨线连接到目标轨道

已有行程时，在地图右键查询目标轨道，点击该轨道右侧的链条图标“连接到此轨道”。先从当前末端沿已确定方向寻找最短连接；找不到时，逐次尝试回退 1～10 条轨道，优先少回退，再按实际距离选最短路径。

精确连接及最多 10 条回退都失败时，会沿所选轨道的同线连续部分查找可达汇入点。同线按本地线路名称、编号和轨道类型匹配，遇到同线分支或中途歧义连接就停止扩展，不擅自选支线。

找到替代位置时，地图同时标出原选位置、推荐汇入点及沿线偏移距离，按钮显示“改接推荐位置”；必须明确确认才会改接。未找到时，会根据实际搜索结果提示需要折返、搜索超限或未找到符合方向的连接，不把搜索失败直接当作现实铁路不通。

地图上橙色预览新增连接，红色预览将移除的轨道。点击“确认连接”后接入当前行程段；取消或寻路失败不会修改行程。“作为下一段继续”仍用于独立换乘。

连接查找由后端直接使用本地 PBF 索引，一次请求返回方案和所需轨道数据。前端只提交末尾最多 11 条轨道的方向、保留范围、目标 ID，以及防止接回旧轨迹的节点和轨道 ID 约束，不上传整段坐标；服务器不保存行程或 Cookie。普通选轨、回退和裁剪仍由前端计算，确认连接也在前端应用。

寻路使用本地 PBF 轨道的共享节点，支持 way 中途连接和部分轨道，不限于同一线路关系。每次尝试最多寻找 50 公里的连接，复杂网络另有搜索量上限；超过限制时请靠近跨线位置再试。不会自动原路折返或选择明显折返的连接。OSM 的错误连接仍可能影响结果，请先查看预览。

### 沿关系继续

已有行程时，点击上方“当前轨道”的名称／ID，直接展开该轨道的详情和所属关系，无需重新右键查询。点击“直接所属关系”中的关系名称预览。首条完整轨道位于连续链端头时，自动确定朝链内延伸的方向；位于链中间时，仍需先选择下一条轨道或指定起点方向。关系行右侧的双右箭头表示“沿此关系继续”，定位图标仍用于查看范围。

- 选中关系后，沿已确定方向寻找没有歧义的连续轨道。远处的分支不阻止加入前方确定的部分；关系外的岔道不影响这次明确选择。
- 双箭头不可用时置灰，悬浮立即显示原因，例如尚未确认方向、关系内有分支或已经到末端。
- 悬浮可用的双箭头，只预览本次将新增的前方部分，不移动地图；移开恢复关系预览。
- 点击加入前方连续轨道，到关系缺口、分支或接回已选轨迹前停下，保留当前行程段。若下一条 way 中途存在共点分支，则停在该 way 之前，由原有候选列表手动选择；不会自动跨过岔口或进入其他关系。
- 加过下车站可使用“在此结束本段”；退回仍每次只缩短一条轨道，不撤销整组加入。

### 轨道跨过车站时，调整行程起终点

OSM 的一条轨道（way）不一定以车站为起终点，有时会连续穿过多个车站。直接保留整条 way，可能会把上车站之前或下车站之后的轨迹也包含进去。这时需要在实际乘车站的位置截取轨迹。

例如，一条 way 依次经过 A、B、C 站，你实际从 B 站出发，就用“从此开始本段”把起点设在 B 站；如果在 B 站下车，就用“在此结束本段”去掉 B 站之后的轨迹。

- **上车站位于首条 way 中间**：先选中该轨道，在地图上靠近上车站的轨道位置右键选择“从此开始本段”，再从列表中的 `way-A` / `way-B` 选择出发方向。不指定起点时按整条轨道开始，不显示 A/B。修改当前段起点仅在首条轨道阶段可用。
- **已选轨迹越过下车站**：在地图上靠近下车站的已选轨道位置右键选择“在此结束本段”。程序将点击位置投影到轨迹上，截掉该点之后的部分，包括后续整条轨道，因此自动推进过头时无需逐条退回。
- 结束位置需在轨迹 150 米以内；方向未确定时，结束操作置灰。截取不移动地图，地图、距离和 KML 同步更新。
- “退回一条轨道”始终缩短行程，**不会撤销截取**；若末尾已截取，就移除剩余部分。

### 保存与清空

行程只保存在当前页面内存中，**刷新页面会清空**，不同标签页互不影响。“清空”按钮也可清除全部行程，且不移动地图。

地点搜索历史单独保存在浏览器本地，最多 10 条，可在搜索下拉列表中清空。

## 5. 导出

### KML

选择全部行程或单段，再点击“下载 KML”。

- 一个文件保存多段独立轨迹，换乘处不强行连线；保留实际截取位置。
- 每段优先使用起始轨道的线路色，没有有效颜色时按行程段轮换颜色；地图与 KML 一致。
- 下载前根据本地车站数据建议起点、换乘站和终点名称，可选择候选或手动修改。
- 站名优先使用 OSM 的 `name`。优先按轨道停车点和线路停靠站关联，缺少关联时用附近车站建议，并标明“附近车站”。
- 文件名形如 `A → B → C.kml`。换乘站名称不同时使用 `A → B1（B2） → C.kml`；相同名称不重复显示。

### Overpass

在“更多”中复制 Overpass 查询或查看查询内容，再到 [Overpass Turbo](https://overpass-turbo.eu/) 使用。

**Overpass 返回完整 way，不能表达截取后的部分轨道。** 需要准确起终点时，请直接下载 KML；复制含截取轨道的查询时，页面也会提示这一点。

## 6. 维护与排查

### 查看日志

日志为普通文本，包含时间、级别、请求编号、操作摘要和错误信息，异常堆栈分行显示。单文件最大 5 MiB，保留 3 份轮转历史。

```bash
tail -f "app/data/logs/rail.log"
```

可用 `request_id` 关联请求，用 `page_id` 关联同一页面的操作。日志不记录 Cookie 或完整行程几何。此前已生成的 JSON 日志不会自动转换。

### 只更新车站索引

通常不需要单独执行；完整解析已包含车站索引。已有轨道索引、只需补建车站信息时，停止服务，使用与轨道索引相同的 PBF：

```bash
python "app/parse_osm.py" --stations-only "/实际路径/地图.osm.pbf"
```

完成后重启服务。

### 下载细节

下载最多使用 16 个连接，支持 HTTP/HTTPS 重定向。分段文件和 `download.json` 保存在同一下载目录；远端大小及 ETag/Last-Modified 未变时可续传或复用，版本变化则重新下载。

不支持 Range 的服务器使用单连接下载；缺少可靠版本标识时，跨次运行重新下载。分段合并期间需额外容纳一份 PBF 的磁盘空间。系统 Downloads 查询不可用时，回退到用户主目录下的 `Downloads`。

### 常见问题

| 问题 | 处理方式 |
| --- | --- |
| PBF 解析慢或内存占用高 | 优先选择更小区域的数据 |
| 能搜索地点，但附近没有轨道 | 检查该位置是否在当前 PBF 覆盖范围内，以及 OSM 是否标记为支持的轨道类型 |
| 在线地点搜索失败 | 检查网络；可通过 `RAIL_GEOCODER_URL` 配置兼容 Nominatim 的搜索服务 |
| 服务换了索引，旧页面无法继续操作 | 先导出已有行程，再点击“清空”，绑定新数据源 |
| 剪贴板复制失败 | 在“更多”中查看查询内容并手动复制 |

## 开发说明

行程推进、退回、截取、分支推荐和 KML 生成均在浏览器完成。Flask 提供本地索引查询、在线地名搜索代理和诊断记录，不保存行程会话。轨道数据按需加载，在当前页面内存中复用。

```text
rail-explorer/
├── README.md
├── requirements.txt
├── app/
│   ├── app.py                 # Flask 入口
│   ├── parse_osm.py           # PBF 解析与索引生成
│   ├── pbf_download.py        # 多连接下载与续传
│   ├── diagnostics.py         # 日志与诊断
│   ├── nearby.py              # 附近轨道与关系查询
│   ├── geocoding.py           # 在线地名搜索
│   ├── station_*.py           # 车站索引与地图展示
│   ├── stations.py            # 端点车站建议
│   ├── static/                # 前端行程计算与地图交互
│   ├── templates/index.html   # 页面
│   └── data/                  # 本地索引与日志，不入 Git
└── tests/                     # Python 与前端算法测试
```
